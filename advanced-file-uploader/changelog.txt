** Extendons: File Uploader for WooCommerce **

2025-08-01 - version 1.0.3
* Implemented "Change Upload File" feature on the Thank You page.
* Minor changes and bug fixes.
* Added Accept/Reject functionality for uploaded files at the cart level in the admin backend.
* Implemented email notifications to customers on file Accept/Reject status updates.
* Enabled Accept/Reject status control on the "Edit Order" screen (Product Level).
* Added "Change Upload File" feature on the View Order page — allows users to preview, download, and check file status.

2025-07-16 - version 1.0.2
* Fixed issue where file upload option was not visible on the frontend, even when required.
* Resolved backend redirection issue after updating a rule; now properly redirects to “Manage All Rules” page.
* Corrected issue where rule name displayed incorrectly in the admin panel.
* Fixed menu visibility problem when editing rules in the backend.
* Addressed issue where upload and other related buttons were missing on Cart and Checkout pages after uploading a file.
* Fixed behavior where the uploaded file was not retaining the original filename; user-uploaded files now maintain their original names.
* Ensured the "required" text is properly displayed on the upload file popup.
* Added drag and drop file upload support for a smoother user experience.
* Introduced a shortcode to display the file upload button on any page or product.
* Implemented option to define a custom folder for storing uploaded files.
* Improved rule application logic to allow a single rule to work across multiple pages (Cart, Checkout, etc.).
* Fixed issue where required files were incorrectly added to the cart even if the user did not upload any files, when the rule was applied to only a single product.

2025-05-15 - version 1.0.1
* Fixed issue preventing "Add to Cart" functionality on mobile devices.
* Resolved session handling for guest users.
* Ensured entire attachment is removed from cart when a single image is deleted.
* Fixed "Modify File" button behavior in popup on the Thank You page.
* Corrected image count display on product page.
* Minor bug fixes.

2024-09-26 - version 1.0.0
* Initial Release
